실습실 통합 양식 사용 안내

파일명: 실습실_통합양식.html  |  브라우저에서 열어 바로 사용
개요

5개 신청서·결과보고서를 하나의 HTML 파일로 통합한 양식입니다. 인터넷 연결 없이 브라우저(Chrome · Edge · Safari)에서 바로 열어 작성, 임시저장, 인쇄 및 PDF 저장이 가능합니다.

기본 사용법

  • 파일 열기 — 실습실_통합양식.html을 더블클릭하거나 브라우저로 드래그하여 엽니다.

  • 탭 선택 — 상단 탭 버튼을 클릭하여 해당 신청서로 이동합니다.

  • 양식 작성 — 각 항목을 빠짐없이 입력합니다. * 표시 항목은 필수 입력란입니다.

  • 임시저장 — 작성 중 💾 임시저장 버튼으로 내용을 저장해두면, 다음에 같은 파일을 열었을 때 📂 불러오기로 복원할 수 있습니다.

  • 저장 및 인쇄 — 🖨 저장 및 인쇄 버튼을 클릭하면 임시저장 후 인쇄 창이 열립니다. 프린터 대신 PDF로 저장을 선택하면 PDF 파일로 저장됩니다.

🖨
저장 및 인쇄

💡 임시저장 주의사항 — 저장 데이터는 같은 브라우저·같은 파일에서만 유지됩니다. 브라우저 캐시 삭제, 시크릿 모드, 다른 기기에서는 불러올 수 없습니다.
초음파 장비 사용 안내

초음파영상장비 사용 시 아래 절차를 반드시 준수하세요.

  • 사용신청서(탭 ④) 작성 및 제출 — 사용 전 반드시 제출하고 담당 조교의 승인을 받아야 합니다.

  • 장비 사용 — 승인된 장비만 사용하며, 사용 중 이상 발생 시 즉시 담당자에게 보고합니다.

  • 결과보고서(탭 ⑤) 작성 및 제출 — 사용 종료 후 반드시 제출합니다.
