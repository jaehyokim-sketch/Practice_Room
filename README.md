## 개요

실습실 사용과 관련된 5종 양식을 하나의 HTML 파일로 통합한 웹 기반 양식 시스템입니다.  
별도의 설치 없이 브라우저에서 바로 사용할 수 있으며, 작성 후 인쇄 또는 PDF 저장이 가능합니다.

## 주요 기능

- **홈 아이콘 메뉴** — 신청서·사용일지·사용안내를 카드 형태로 선택
- **임시저장 / 불러오기** — 브라우저 localStorage에 자동 저장, 이어쓰기 가능
- **인쇄 / PDF 저장** — 브라우저 인쇄 기능으로 PDF 출력 지원
- **초기화** — 양식 전체 및 임시저장 데이터 삭제
- **다크 모드** — 시스템 설정에 따라 자동 전환
- **반응형 레이아웃** — PC·태블릿·모바일 화면 대응

## 사용 방법

### 로컬 사용

1. `index.html` 파일을 다운로드합니다.
2. 브라우저(Chrome / Edge / Safari)에서 파일을 엽니다.
3. 홈 화면에서 원하는 양식 카테고리를 선택합니다.
4. 양식을 작성한 후 **임시저장** 또는 **인쇄**를 누릅니다.

### GitHub Pages 배포

```bash
# 저장소에 index.html 업로드 후 GitHub Pages 활성화
# Settings → Pages → Source: main branch / (root)
```

배포 URL: `https://<username>.github.io/<repository>/`
