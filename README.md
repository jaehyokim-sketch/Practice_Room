# 원광대학교 한의과대학 실습실 통합 양식 사용 안내

> 파일명: `실습실_통합양식.html`  
> 관리자: 경혈학교실 / 임상술기센터  
> 문의: 063-850-6448

---

## 개요

5개 신청서·결과보고서를 하나의 HTML 파일로 통합한 양식입니다.  
인터넷 연결 없이 브라우저에서 바로 열어 작성·인쇄·PDF 저장이 가능합니다.

---

## 탭 구성

| 탭 | 양식명 | 제출 시점 |
|----|--------|-----------|
| ① | 공동실습실1 사용 신청서 | 사용 **전** |
| ② | 임상술기센터 사용 신청서 | 사용 **전** |
| ③ | 공동실습 사용 결과 보고서 | 사용 **후** 필수 |
| ④ | 초음파영상장비 사용신청서 | 사용 **전** |
| ⑤ | 초음파영상장비 사용 결과보고서 | 사용 **후** 필수 |

---

## 기본 사용법

### 1. 파일 열기
`실습실_통합양식.html` 파일을 더블클릭하거나,  
브라우저(Chrome · Edge · Safari)로 드래그하여 엽니다.

### 2. 탭 선택
상단 탭 버튼을 클릭하여 해당 신청서로 이동합니다.

### 3. 양식 작성
각 항목을 빠짐없이 입력합니다.  
`*` 표시 항목은 필수 입력란입니다.

### 4. 저장 및 인쇄

| 버튼 | 기능 |
|------|------|
| 💾 임시저장 | 현재 탭의 입력 내용을 브라우저에 저장 |
| 📂 불러오기 | 마지막으로 임시저장한 내용을 복원 |
| 🖨 저장 및 인쇄 | 임시저장 후 인쇄 창 실행 |
| ↺ 양식 초기화 | 현재 탭의 모든 입력 내용 및 임시저장 삭제 |

> **임시저장 주의사항**  
> 임시저장 데이터는 **같은 브라우저·같은 파일**에서만 유지됩니다.  
> 브라우저 캐시 삭제, 시크릿 모드, 다른 기기에서는 불러올 수 없습니다.

---

## PDF 저장 방법

1. 🖨 **저장 및 인쇄** 클릭
2. 프린터 목록에서 **PDF로 저장** 또는 **Microsoft Print to PDF** 선택
3. 저장

---

## 초음파 장비 사용 안내

- **삼성메디슨 / HS50**: 방과후 개별 사용 금지, 진단학교실 사용 허가 조건
- 사용 전 반드시 초음파영상장비 **사용신청서(탭 ④)** 제출 및 승인 필요
- 사용 후 반드시 **사용 결과보고서(탭 ⑤)** 제출

---

## 결과보고서 미제출 시 불이익

- **공동실습실1**: 결과보고서 미제출 시 추후 실습실 이용에 제한을 받습니다.
- **초음파영상장비**: 결과보고서 미제출 시 추후 장비 사용에 제한이 있을 수 있습니다.
